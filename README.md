# Shubhra — Original Art

Hand-built art shop: plain HTML/CSS/JS, no build step, no monthly fees.

- **Edit content:** open `/studio.html` on the live site → make changes → **Publish**.
- **Data:** everything lives in `data/site-data.js` + images in `art/`.
- **Design:** colors & fonts at the top of `assets/css/style.css`.
- **Hosting:** GitHub Pages (Settings → Pages → Deploy from branch `main` / root).

See `START-HERE.html` (shipped with the download) for the full launch guide.
